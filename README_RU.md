## 1) Запуск Mini App локально (как ты делал через CMD)

1) Распакуй архив.
2) Открой **CMD** в папке проекта (где `package.json`).
3) Выполни:

```bat
npm i
npm run dev
```

Открой в браузере:
- http://localhost:3000

> Если в PowerShell ругается на `npm.ps1` — используй CMD (у тебя уже получилось).

## 2) Запуск Telegram‑бота

### 2.1 Создай бота у BotFather
- `/newbot`
- Сохрани токен.

### 2.2 Задай переменные окружения

Самый простой способ — создать файл `.env` НЕ будет работать автоматически без dotenv,

```bat
npm run bot
```

Если хочешь `.env`, можно позже добавить пакет `dotenv`.

## 3) Как “объединить Mini App с Telegram” (чтобы открывалось внутри Telegram)

Telegram Mini App почти всегда должен открываться по **HTTPS**.

### Вариант A (быстрый тест): ngrok
1) Запусти mini app: `npm run dev`
2) Запусти ngrok:
```bash
ngrok http 3000
```
3) Возьми ссылку вида `https://xxxx.ngrok-free.app`
4) Запусти бота с:
```bat
set BOT_TOKEN=...
set WEBAPP_URL=https://xxxx.ngrok-free.app
npm run bot
```

Открой бота → `/start` → кнопка Mini App.

### Вариант B (норм хост): VPS + домен + HTTPS
Хостишь Node.js сервер (server.js) на VPS, ставишь Nginx/Caddy и сертификат (Let’s Encrypt).
Тогда `WEBAPP_URL` будет твоим доменом.

## 4) Частые проблемы

### “Не видно 3D” или “не загружается библиотека 3D”
Верхний скрипт берётся с CDN `unpkg.com`. Если он блокируется или нет интернета —
3D может не появиться. Решение:
- проверить интернет/впн/блокировки
- позже можно “запаковать” библиотеку локально

### “Ник не грузит скин”
- проверь правильность ника
- проверь интернет
- попробуй другой ник (например `Notch`)
